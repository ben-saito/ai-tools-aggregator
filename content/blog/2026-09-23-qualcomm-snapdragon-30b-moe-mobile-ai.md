# Qualcomm Launches Smartphone Chips with On-Device 30B MoE Model Support

Qualcomm has unveiled two new smartphone system-on-chip products with a sharp focus on AI capabilities, the company announced on September 22, 2026. The flagship chip can run a 30-billion-parameter mixture-of-expert (MoE) model entirely on-device, a significant step forward for on-device AI inference on mobile hardware.

---

## On-Device Mixture-of-Experts

The standout feature of Qualcomm's new top-tier chip is its ability to execute a 30B parameter mixture-of-expert model locally on the device. MoE architectures activate only a subset of a model's "expert" layers per inference, allowing larger models to run within tighter memory and compute budgets. Running such a model without cloud connectivity brings privacy-sensitive AI workloads entirely within the user's device.

The second chip in the lineup targets the mid-range segment, extending AI features to a broader smartphone price tier.

---

## Implications for Mobile AI

Until recently, running large language models on smartphones required cloud API calls, introducing latency, connectivity dependency, and privacy considerations. Qualcomm's push toward on-device MoE inference reflects a broader industry trend of shrinking capable AI models to fit mobile memory and power envelopes.

The ability to run a 30B MoE model on-device could enable faster, more private AI experiences in voice assistants, real-time translation, and productivity applications without round-trip server calls.
