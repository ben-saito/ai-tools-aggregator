# OpenAI Cyber Defense Program Access Temporarily Revoked for Security Researchers

Several security researchers report that OpenAI suddenly revoked their access to a limited-access program that removes some restrictions on using its AI tools for cybersecurity research. OpenAI confirmed the issue was caused by an error.

---

## Trusted Access for Cyber Program Abruptly Suspended

On Wednesday, multiple researchers on OpenAI's official support forums and on X reported having their access to the Trusted Access for Cyber (TAC) program revoked. The people said that when they opened ChatGPT's Cyber page, a message appeared saying their identity could not be verified.

The idea behind TAC and the Cyber Vulnerability Program (CVP) is to give trusted defenders better models so they can report bugs and vulnerabilities to companies, with the aim of getting flaws patched faster. The programs provide elevated access to OpenAI's AI models for legitimate security research purposes.

OpenAI confirmed the access revocation was the result of an internal error, not a deliberate decision. "This was caused by an error," an OpenAI spokesperson said. The company is working to restore access for affected researchers.

---

## Implications for Security Research Community

The incident highlights the delicate balance between providing AI capabilities for defensive security research and maintaining strict controls to prevent misuse. Security researchers rely on these programs to identify vulnerabilities in software systems and report them to affected companies before malicious actors can exploit them.

The temporary loss of access creates friction for researchers who have built workflows around OpenAI's enhanced AI capabilities. It also raises questions about the reliability of access control systems for sensitive AI model tiers.
