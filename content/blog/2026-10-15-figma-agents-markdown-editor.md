# Figma adds Markdown editor and agent features for design workflow automation

---

Design platform Figma announced a new Markdown-based editor to help define a company's design, bring in design and code libraries, and integrate with the Payload headless content management system during its Config India event.

The new editor allows teams to write and maintain design documentation directly within Figma, bridging the gap between design specifications and code libraries. The integration with Payload CMS enables designers to pull in content structures and see how designs will render with real data.

"We heard from designers that they were constantly switching between tools to maintain design systems documentation," said a Figma product manager. "This editor brings that workflow into Figma itself."

The agent features announced at the event further expand Figma's automation capabilities. The platform is positioning itself as a hub for AI-powered design workflows, where agents can handle repetitive tasks like updating design tokens, generating asset variants, and ensuring consistency across large design systems.

The Config India event, held in Bangalore, brought together designers and developers to explore the latest in design technology. Figma's announcements reflect a broader push toward making design platforms more programmable and automated.

The new features are rolling out to Figma organizations over the coming weeks, with additional integrations planned for the future.
