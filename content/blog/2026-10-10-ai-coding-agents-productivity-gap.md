# AI Coding Agents Generate More Code, But Not More Software

---

A new study examining AI coding agents in production environments reveals a counterintuitive finding: while these tools dramatically increase code generation output, they have not proportionally improved the delivery of working software features.

The research, conducted across multiple enterprise development teams deploying AI coding assistants, found that agents optimized for code volume tend to generate larger quantities of code that requires extensive review, refactoring, and debugging — effectively shifting work rather than eliminating it. One team observed a 40% increase in code commits alongside a net-zero change in shipped features over a six-month period.

Key findings include: agents often produce functionally correct but architecturally inconsistent code when working across larger codebases; review cycles became longer because human engineers needed to understand and validate AI-generated logic; and technical debt increased measurably in teams that relied heavily on agents without strong review discipline.

The core tension emerges from a misalignment between what coding agents optimize for — token output, completion of discrete functions — and what software teams need — stable, maintainable, integrated features. Agents lack awareness of downstream maintenance burden, legacy system interactions, and the implicit requirements that human developers carry from institutional memory.

Industry observers suggest the pattern reflects a broader learning curve: organizations that achieved productivity gains paired AI agents with stronger review protocols, explicit architectural guardrails, and human oversight focused on integration rather than correctness.
