# Cursor Launches Origin, a Rival Code Hosting Platform to GitHub

Cursor, the AI-powered code editor known for its close integration with development tools, is launching Origin — a new code-hosting platform designed to rival GitHub. The move capitalizes on growing developer frustration with GitHub's recent performance issues.

---

## GitHub's Struggles Create Opening for Competitors

For years, GitHub has been the de facto standard for code hosting and version control among developers. However, in recent times, the platform has faced widely reported outages and performance degradation. Cursor sees an opportunity to attract disaffected developers with a new offering.

Cursor, which is now officially a part of SpaceX, launched Origin this week. The platform is designed to handle all the core functions developers typically use GitHub for: collaborative coding, pull requests, code review, and CI/CD integration.

---

## AI-Native Development Environment

Given Cursor's background in AI-assisted coding, Origin is expected to deeply integrate AI capabilities into the code hosting experience. The platform likely aims to differentiate itself through tighter AI-assisted code review, automated bug detection, and intelligent merge conflict resolution.

The timing is notable: as AI coding assistants become more prevalent, the integration between code editing and code hosting becomes increasingly important. Cursor's position as an AI-first editor gives it unique insights into what developers need from a code platform.
