# GitHub Copilotトークン課金の衝撃とAI開発の今后

2026年5月、GitHub Copilotの料金体系刷新 開発者コミュニティの反発を呼んでいる。同時に、MetaのAIペンダント開発、SoftBankのフランスへの巨額データセンター投資など、AIインフラへの投資も加速している。本稿では今週のAI開発相关新闻をまとめる。

---

## GitHub Copilot：トークン従量制の導入に開発者たちが困惑

GitHubはMicrosoft Build 2026の基調講演で、GitHub Copilotの新たなトークン課金を正式に発表し、瞬く間に開発者コミュニティの反発を呼んだ。「What a joke」——TechCrunchのタイトルにもあるとおり、Copilotの長期ユーザーからは「無制限利用が終わった」「実際のトークン消費量が可視化されて請求が予測不可能になる」などの声が上がっている。

これまでは月額10ドル（约1100円）または月額19ドル（约2100円）の固定料金制だったが，新的従量制では1トークンあたりの料金で加算される。開発者にとって大きな点は，月額上限が設定されているかどうかが明確でない点だ。固定料金であれば予算管理が容易だったが，従量制では繁忙期の請求額が読みきれず，チーム単位でのコスト管理が複雑化する。

Microsoft是这个変更を「より公平な料金体系」と説明しているが，開発者からは「浪費を招く設計では」という指摘もある。GitHub CEOのThomas Dohmkeは「現在の方式是，大量のライトユーザーに不利だった」と弁解するが，固定ユーザーからの不支持は明らかだ。現在Copilotの有料ユーザーは新料金体系への移行を迫られており，チーム管理者にとっては詳細なコスト分析が必須となった。

## Meta、AIペンダント開発を正式に認める——Limitlessの買収がその起点

MetaがAI駆動のペンダント型デバイスを開発していることがThe Informationの報道で明らかになった。Metaは2025年末にAIデバイススタートアップのLimitlessを買収しているが，この技術がベースになっているという。

Limitlessが開発したペンダントは，シャツに取り付けたりネックレスとして身につけたりして会話内容を記録するタイプのデバイスだった。Metaは買収時に「AI対応デバイスの開発を加速する」と述べていたが，製品化の動きはこれまでは不明確だった。

新しいレポートによると，MetaはAI眼鏡のライン拡張も計画しており，「Wearable for Work」という法人向けサービスも検討中だ。ウェアラブル機器の挑戦を続けてきたMetaだが，Reality Labsは2026年第1四半期に約40億ドル（約600億円）の赤字を計上しており，ハードウェア側の成功は焦眉の急だ。

Metaだけでなく，AppleやRabbitなど多家参入が市場に殴り込みを図るAI衣類向け製品群だが，一般消費者への普及はなお難しい。プライバシー不安，清潔なマーケティング，そして「便利さ」が十分に証明されていないことが主な障碍とされる。ただ，OpenAIも精力的にAI機械的开发を進めており，2026年はこの分野で本格的な突破口が期待される年になりそうだ。

## SoftBank、フランスに750億ユーロのAIデータセンター建設を約束

SoftBank Groupは5月30日，フランス国内に最大750億ユーロ（約87億ドル）のデータセンターを建设すると表明した。目标是フランス国内に最大5ギガワットのデータセンター容量を確保すること。第1段階ではDunkirk，Bosquel，Bouchainにデータセンターを設置し，2031年までにHauts-de-France地域に3.1ギガワットの容量を提供する予定だ。

SoftBankはOpenAIの投資家であると同時にその顧客でもある。この投資は「ヨーロッパにおける最大のAIインフラ投資」（SoftBank声明）となり，フランス経済长官のRoland Lescuraは「マクロン大統領の野心の実証」と評価した。

一方，米国内では環境への影響や電力グリッドへの负荷が指摘され，数据センター建設に対する反発が強まっている。SoftBank自身もOhio州に生涯9.2ギガワットの天然ガス火力発電年で動くデータセンターを建設する計画を公表しており，数据センターと電力供給の問題は世界的な課題として浮上している。

## 「タダで部屋を清掃，代わりにロボットに學ばせる」——Shiftのビジネスモデル

AI訓練の战场上では，独創的なアプローチを取るスタートアップが诞 生している。Shiftという名の企業は，ニューヨーカー市民向けに部屋を清掃するサービスを完全に無料で提供すると表明した。「部屋の清掃と引き換えに、ロボットが使用するカメラやセンサー類での撮影許可を取得する」——そう説明するのは，同社の意思代表人だ。

このモデルは「家政婦の代わりに情報を取得する」という点で，従来のAI訓練と異なる。ClaudeやGeminiのような大規模言語モデルはWeb上のテキストや画像で訓練されるが，ロボット制御のAIはリアルな三次元空間での操作経験が必要だ。しかし，ロボットへの適切な訓練データは極めて珍しく，一般家庭での撮影はプライバシー上の問題も絡む。

同社はニューヨーカー在住の多くの家庭が既にこのサービスに登録しており，ニューヨーク以外的都市への拡大も計画している。家事労働の情報プライバシー問題は残るところだが，ロボットAIの訓練データ収集企業として，新しいビジネスカテゴリーを切り開こうとしている。

## Microsoft 365 Copilot，速度とデザインを大幅改良

Microsoftは5月28日，Microsoft 365 Copilotの改良版を公开发した。最も注目すべき変更は表示速度の2倍化と、より简洁なUIの導入だ。AI搭載の生産性ツール市場はGoogle Workspace AIやその他の競合との竞争が激しく，Microsoftは基本性能の改善で差別化を図っている。

新しいCopilotはバックグラウンドでMicrosoft Graphを活用し，ユーザーごとにパーソナライズされた Suggestionを行う。电子邮件の下書き，Meeting钞約，文書の要約などができるのは従来通りだが，タスク完了までの step 改善が最も注目すべきポイントだとしている。

Microsoft 365 Copilotは企业向けの月額30ドル（约3300円）で提供されており，个人利用のGitHub Copilotとは料金体系もターゲットも異なる。しかし，生成AI搭载の办公套裝が当たり前になりつつある現在，价格と実用性のバランスをどう取るかが製品戦略の关键となりそうだ。
