# Ramp Launches AI Model Router, Letting Companies Switch Between LLMs via API

Ramp has launched its own AI model routing service called "Router," allowing users and companies to access and switch between various large language models through a single API.

The service enables developers to call models from OpenAI, Anthropic, Google, and other providers through one interface. Ramp says companies can achieve up to 60% cost reduction on certain workloads by intelligently routing requests to the most cost-effective model for each task.

AI model routing has gained attention as a way to optimize costs given the varying performance and pricing across different LLM providers. A single API call through Router can route to the optimal model based on the specific workload.

Ramp's target is enterprises looking to simplify AI adoption without managing multiple provider relationships or complex model selection logic. Engineers can call the Router API without configuring individual provider settings.

Pricing varies by model, but Ramp's routing algorithm is designed to reduce costs while maintaining performance. The service is available immediately for Ramp's existing customer base.
