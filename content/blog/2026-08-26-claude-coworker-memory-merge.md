# Anthropic Merges Claude Memory Systems Across Chat and Cowork

One of the most persistent pain points in using AI agents is the constant need to rebrief the system on information it should already know. Anthropic is addressing this with a significant update to Claude's memory architecture.

On Tuesday, Anthropic announced it is merging the memory system used by Claude's consumer chat interface with the Claude Cowork enterprise product. The result: Claude will consistently retain information learned across different interaction contexts.

Previously, information shared in one context often failed to transfer when users switched to another. With the unified memory system, context learned in research phases now seamlessly carries forward into action-oriented tasks.

Anthropic is also exposing what Claude has retained, giving users visibility into the AI's memory and the ability to read, edit, or delete stored information. This transparency lets users manage what the model knows about them and their work.

The update improves workflow continuity for knowledge workers who move between research, drafting, and execution tasks throughout their day.
