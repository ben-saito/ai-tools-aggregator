# LibreOffice Declares 'No AI' as a Software Feature

---

The Document Foundation, the nonprofit behind the open-source LibreOffice office suite, has made a deliberate choice: **no AI integration in the default configuration**. For LibreOffice, saying "no AI" is now a marketed feature.

## The Position

LibreOffice's stance centers on **user privacy**. AI features in productivity software typically require sending document content to cloud APIs for processing — a requirement that conflicts with LibreOffice's user base, which includes privacy-sensitive individuals, enterprises, and governments. By keeping AI out of the default configuration, The Document Foundation ensures users aren't inadvertently sending sensitive data to third-party AI providers.

The organization has not ruled out AI integration entirely, but any AI features would be opt-in, clearly labeled, and require explicit user action to enable.

## Contrast with Microsoft Copilot

Microsoft's approach in Microsoft 365 embeds Copilot deeply into Word, Excel, and PowerPoint, with document content processed on Microsoft's servers by default. Corporate IT departments must actively configure data handling policies; the default behavior sends content for AI processing.

LibreOffice's model inverts this — **privacy by default**, with AI as an optional addition.

## Market Positioning

The "no AI" positioning appeals to a specific market segment: organizations in regulated industries, government agencies, and enterprises with strict data residency requirements. For these users, an AI-free default isn't a limitation — it's a prerequisite.
