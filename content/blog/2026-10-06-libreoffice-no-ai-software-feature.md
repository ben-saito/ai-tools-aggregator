# LibreOffice Says No AI Is Now a Software Feature

The Document Foundation, the nonprofit behind the open source LibreOffice office suite, has formalized what many in the privacy-conscious open source community have long argued: declining AI integration is a feature, not a limitation. In a blog post published this week, the organization reiterated that the latest release of LibreOffice contains no generative AI features and that this is a deliberate design position.

---

## A deliberate stance on AI by default

LibreOffice has long allowed users to extend its functionality through optional extensions. That philosophy now explicitly extends to AI capabilities. Users who want AI assistance can install extensions that connect the document editor to local AI models running on their own hardware, but the default installation ships with no AI features whatsoever.

The reasoning centers on data sovereignty. "Any organisation handling confidential, legally privileged or personal data needs to know where that data goes," the foundation said in its blog post. "The only assurance that survives an audit is that it does not leave the machine." In an era when AI features increasingly require cloud processing, LibreOffice is betting that the demand for offline, air-gapped document editing will only grow.

This stance contrasts sharply with the direction taken by most commercial office software, where AI features are increasingly bundled by default and often send user documents to cloud endpoints for processing.

---

## Privacy-first positioning in a crowded market

The timing of the announcement follows the late August release of LibreOffice 24.x, in which the foundation first articulated this "no AI by default" position. The blog post accompanying that release framed it explicitly as a privacy feature rather than a rejection of AI technology itself. The foundation says it does not reject AI outright, but that users should have to opt in rather than have AI processing silently enabled.

For enterprise users in regulated industries, the distinction matters. Financial services firms, law practices, and healthcare organizations face strict rules about where client data travels. A document editor that makes no network requests for AI processing simplifies compliance auditing considerably.

The foundation also pointed out that local AI models have matured to the point where running a capable assistant entirely on a local workstation is now practical. Extensions that connect LibreOffice to locally hosted models via a local API endpoint can provide AI assistance without any data leaving the device.

---

## Implications for the AI integration debate

LibreOffice is not the only software project to push back against default AI integration. Several security-focused and privacy-oriented projects have made similar arguments in recent months. What distinguishes the LibreOffice announcement is the scale of the user base and the explicit framing of "no AI" as a positive product attribute.

The foundation is essentially arguing that in a world where every software vendor is racing to add AI, choosing not to do so is itself a differentiator. Whether that argument resonates commercially remains to be seen, but the underlying concern about data handling in AI features is one that IT departments and compliance teams are increasingly raising.
