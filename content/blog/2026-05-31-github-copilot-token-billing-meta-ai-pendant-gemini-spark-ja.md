# AI開発ニュース 2026年5月31日版：GitHub Copilot新料金体系に开发者抗议、Meta AI pendant発売へ

GitHub Copilotのトークンベース課金導入に开发者社区から強い反発が起きている中、MetaはAI搭載 Pendant の開発を进的進めるなど、ハードウェアとソフトウェアの両面でAIエコシステムの变革が加速している。本稿では、Microsoft/GitHub Copilotの新しい料金体系、MetaのAI Pendant、Google Gemini Sparkの24時間AIアシスタント、そしてTikTokにおけるAI生成フェイク人物の問題をまとめる。

---

## GitHub Copilot、新しいトークンベース課金が开发者から猛烈な批判浴びる

GitHub Copilotの「黄金時代」が終わった——Microsoftの代码補完ツールGitHub Copilotが、新的なトークンベース課金を導入したことで、开发者コミュニティから激しい反発が起きている。TechCrunchが伝えたところによると、「いい加減にしろ」という声が多数上がっている。

###新しい課金体系の詳細

従来の月額固定制から转变为トークンベース制により、中小企業や個人開発者にとってコスト予測が困難になったことが批判の主因。プロジェクトの規模やコード生成量によって月額費用が変動する構造は、特に常時起動型のAIコード補完依赖するチームにとって予算管理上の課題となる。

开发者社区からは以下の点が問題視されている：

- **コスト予測の困難さ**: プロジェクト规模に比例して課金が変動し、月次予算立てが不可能に
- **小企业への悪影響**: 小规模チームや个人開発者にとって、固定月額制の方が効率的だった
- **既存のワークフローへのインパクト**: 現在の開発プロセスを見直す必要性が発生

MicrosoftはCopilotの収益化戦略を最適化すめいているとされるが、开发者コミュニティの反応は厳しく、「いい加減にしろ」という直接的な批判がSNS中心に広がっている。

## Meta、AI Pendantの開発を推進——穿戴型AIデバイスが的主流に

MetaがAI搭載Pendantの開発を进的めていることが明らかになった。TechCrunchによると、MetaはAI驱动的ハードウェアへの大きな赌け正在进行中であり、続々と新しいデバイスを市場投入する戦略だ。

### 製品の特徴と位置づけ

MetaのAI Pendantは、ユーザーの日常的な会話を聞き取り、AIアシスタントとしてリアルタイムで情報を提供することを主目的としている。类似的产品としてはRabbit R1やHumane AI Pinが挙げられるが、いずれも市場での成功は限定的だった。

Metaが目指すのは、**ソーシャルメディアプラットフォームからハードウェア制造商への転換**。既存のMeta QuestやRay-Ban Smart Glassesで培ったテクノロジーを応用し、AI駆動型の生活に優しいデバイスを家庭に届けることを目指す。

### 市场竞争环境

穿戴型AIデバイスは、GoogleのGemini Sparkなど、ソフトウェア中心のAIアシスタントとはアプローチが異なる。Metaの戦略は、AIをいつでも随地利用可能なハードウェア形态で提供することで、日常的なAI利用の敷居を下げることだ。

## Google、Gemini Sparkで24時間AIアシスタントを提供——日常タスクの自动化に挑戦

Googleが24時間体制で動作するAIアシスタント「**Gemini Spark**」を発表し、実際のユースケースでテストされた。TechCrunchの报道によると、このアシスタントは以下のような日常タスク自动化を手伝う：

- **受信トレイの要約作成**: 複数のメールを確認して概要を即座に生成
- **ローカルイベントの計画**: 用户的日历と好みに合わせてイベントを提案
- **リアルタイムな情報提供**:用户的の位置情報と状況を踏まえた recommandation

### 注目すべき論点

Gemini Spark注目すべきは、なぜGoogleがこの製品を独立した商品として出したのかという点。既存のGoogleアシスタントやGeminiアプリでも同等の機能は提供できるはずだが、あえて別ブランドとして展開することでどのような戦略的優位性があるのか、评论家からは疑问が呈されている。

## TikTok ShopでAI生成的黑人人物が泛滥——ECプラットフォームの信頼性問題

TikTok Shopにおいて、AI生成された 흑인 여성 인물图像を使って商品を販売じるケースが急増している。The Vergeが伝えたところによると、「Aliyah」などの名前で作成されたAIアバターが涙ながらに的商品紹介動画を投稿し、視聴者のシンパシーを inúmerしてドロップシッピング商品を販売している。

### 問題の概要

报告によると、訴求力のあるストーリーを描くAI生成人物は以下のステップで活用されている：

1. AIで生成された人物图像と视频を作成
2. 「自作のハンドクラフト商品」として投稿
3. 実際には中存在しない产品和 深センの mass production DROPSHIPPING で大量生産された中国製商品を販売
4. 視聴者の シンパシー，购买意欲を誘導

この现象はTikTok Shop全体の信頼性を损なうものであり、プラットフォーム侧の対応が求められている。
