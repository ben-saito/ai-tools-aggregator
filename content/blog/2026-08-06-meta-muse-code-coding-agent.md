# Meta Launches Muse Code: A Terminal AI Coding Agent for Large Code Bases

Meta has released **Muse Code**, a new terminal-based AI coding agent designed to handle complex software engineering tasks across large code repositories. The agent is currently available in beta and can be installed with a single command, powered by Meta's previously released Muse Spark model.

---

## Parallel Sub-Agents in Isolated Worktrees

Muse Code approaches large projects by spawning multiple sub-agents that operate in parallel within isolated Git worktrees. According to Meta CEO Mark Zuckerberg, this design ensures the developer's working copy is never modified directly — eliminating the risk of conflicting changes.

"In testing, we had it build six features for a game simultaneously with no collisions," Zuckerberg explained in a social media post.

---

## Competitive Positioning Against Codex and Claude Code

The release positions Meta more competitively in the AI coding agent market, directly challenging OpenAI's Codex and Anthropic's Claude Code. Meta's AI chief Alexandr Wang, who leads Meta Superintelligence Labs, emphasized cost efficiency: "We think that for a lot of workflows and a lot of use cases, this can be an incredibly good option, especially from a cost perspective."

---

## Enterprise Expansion Continues

Muse Code follows Meta's broader push into enterprise AI beyond its core advertising business. In June 2026, Meta launched its first customer service and support agent, signaling serious intent to compete in the business AI market.
