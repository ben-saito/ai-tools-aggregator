# AI Coding Agents Generate More Code — But Not More Software

---

## Study Finds Efficiency Gains Get Absorbed by Human Review Bottleneck

A new Harvard study tracking coding practices across hundreds of firms delivers a sobering verdict on AI coding tools: while they dramatically increase code output, they have not increased overall software output or reduced engineering employment. The reason: human code review has become the critical bottleneck.

The researchers, Fiona Chen and James Stratson, analyzed 300 million work events across more than 700,000 employees at over 700 firms using data from engineering analytics firm Jellyfish. The dataset spans 2021 through March 2026.

## The Review Bottleneck

The study found that AI-assisted coding increases the volume of code being written, but that efficiency gain is "absorbed by downstream constraints in the production process." Specifically:

- Code review processes increase significantly in length
- Pull requests are more likely to require revisions
- Reviewers leave more comments on AI-generated code

The finding challenges a common narrative that AI coding tools will dramatically reduce the need for human engineers. Instead, the tools appear to shift work from writing to reviewing — essentially redistributing the labor rather than eliminating it.

## What This Means for Engineering Teams

The study suggests that firms adopting AI coding tools without restructuring their review workflows may see limited net productivity gains. The bottleneck is not in code generation but in the human review process that gates code quality and security.

This mirrors broader concerns in the AI industry about "last mile" problems — AI systems that perform well on individual tasks but create new constraints when integrated into human workflows.
