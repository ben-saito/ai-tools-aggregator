# AI Coding Agents Generate More Code, But Not More Software

---

A new study from researchers at Stanford and MIT has found that while AI coding agents generate significantly more code than human developers, the total amount of functional software produced does not increase proportionally. The research, which analyzed over 50,000 software projects across 18 months, provides the most comprehensive quantitative look at AI's impact on developer productivity to date.

The study measured output in multiple dimensions: lines of code written, pull requests merged, features shipped, and bugs reported. While AI-assisted developers wrote an average of 47% more code than the control group, the number of features shipped per sprint was essentially flat, increasing by only 3%.

The researchers attribute this discrepancy to what they call "output inflation"—AI agents tend to generate verbose, repetitive code that adds lines without corresponding functional value. The study found that AI-generated code had a 34% higher ratio of comments to functional statements and was more likely to contain redundant helper functions.

Quality metrics also showed concerning trends. Projects using AI coding agents had a 23% higher rate of bugs discovered in code review, though these bugs were typically caught before production deployment. More significantly, the "bus factor" problem worsened: codebases with high AI agent usage showed greater concentration of architectural decisions in fewer human developers.

The findings challenge the prevailing narrative that AI coding tools will dramatically accelerate software development. "Generating code is not the same as building software," the researchers wrote. "The bottleneck in most engineering organizations is not the ability to write code, but the ability to understand requirements, design systems, and coordinate across teams."

GitHub, whose Copilot tool is used by millions of developers, disputed the methodology. A company spokesperson noted that the study's timeframe preceded several major improvements to Copilot's context awareness and code suggestion quality.

Despite the caveats, the research has prompted discussion among engineering leaders about how to measure AI tool effectiveness. Traditional metrics like lines of code or commit counts may need to be supplemented with measures of business value delivered.
