# AnthropicがClaude Codeの自動モードをデフォルトにmdash有料ユーザーは来月から

Anthropicは8月9日、Claude Codeの"自動モード"を有償ユーザー向けにデフォルトで有効にすると発表した。自動モードはAIエージェントがコードを自動的に書き換える機能。ユーザーが明示的に無効化しない限り、エージェントが自らの判断でファイルを変更し、テストを実行し、Pull Requestを作成くれる。

Claude Codeは2025年に発売された開発者向け製品。自動モードは当初"要確認"設定だったが、Anthropicは这次の変更で"安全性が確認された"と説明。人間のレビューなしにエージェントがコードを変更できる，这意味着開発リズムの加速と引き換えに、ヒューマン・イン・ザ・ループの原則が薄れる可能性がもたらされる。

Anthropicの発表資料によると、自動モードが有効な環境では、エージェントの平均的なコミット頻度が3倍に向上。誤った変更による障害は0.3%以下だという。だが批判者は"AIが自律的にコードを変更する範囲"について明確な境界線が引かれていないことを危惧する。

今回の発表は、コーディングAIエージェントの自律性がさらに高まる流れの一つ。OpenAIのCodex、GitHub Copilot Workspaceなど、開発者向けAIツールの各社が"自律型"機能を競うように投入している。Anthropicは"必要に応じていつでも人間の視認性を維持できる"としているが、现场からは"デフォルトで自動モードが有効"なことの意味が問われている。

*（本文の情報は2026年8月9日時点のものです）*
