# OpenAI Field Report: Coding Agents Cut Scientific Computing Runtimes by 90%

OpenAI has released a field report documenting eight scientific computing projects where AI coding agents dramatically reduced build and execution times, according to AI News. The report provides concrete evidence that autonomous coding agents can accelerate real-world software development in compute-intensive domains.

The projects covered in the report span genomics, computational chemistry, and physics simulations. In one case, an AI agent rewrote 20,000 lines of dead code in a genomics project, restoring functionality that had been abandoned for years. Scientists reported that while they still verified every output, the time savings were substantial — with some projects seeing runtime reductions exceeding 90%.

---

## Key Findings

- **Projects documented**: 8 scientific computing projects
- **Runtime reduction**: Up to 90%
- **Code rewritten**: 20,000 lines of dead genomics code in one case
- **Human oversight**: Scientists still check every result

---

## Implications for Scientific Computing

The results suggest that AI coding agents may be particularly valuable in scientific computing, where codebases often grow organically over decades and contain legacy systems that few people fully understand. An AI agent can analyze, refactor, and optimize such code without the bias toward preserving existing (often inefficient) patterns that human developers exhibit.

However, the continued need for human verification remains critical in scientific contexts, where errors can have significant consequences.
