# F-Droid Releases Biggest Update in a Decade with New UI and Faster App Installs

F-Droid, the independent Android app store focused on open source software, has released version 2.0 — its most significant overhaul in ten years. The update brings a complete redesign built in Kotlin Compose, making the store substantially more responsive and visually consistent with modern Android design standards.

---

## From the Ground Up: Kotlin Compose Rewrite

The previous F-Droid client had accumulated years of technical debt. Version 2.0 was redesigned from scratch using Kotlin Compose, which is now the standard for modern Android development. The new architecture delivers a much more responsive experience and includes optional support for Android's Material theming system.

The interface has been cleaned up considerably, with clearer visual hierarchy and better organization of the app catalog. F-Droid now includes extensive category organization, drilling down to specialized niches like firewalls, password managers, and VPNs.

---

## Better App Discovery and Installation

One of the primary goals of the redesign was solving app discoverability. When F-Droid first launched, the catalog was small enough to browse manually. Now with thousands of open source apps available, finding the right tool required a better system.

The new version includes a redesigned search tab with better filtering, higher-level categories on the main Discover page, and improved app page layouts. Installation has also been streamlined — F-Droid 2.0 makes it significantly easier to find and install apps without navigating confusing menus.

Google has historically put roadblocks in the way of sideloaded apps, citing security implications. F-Droid 2.0 addresses this by making the installation process smoother and more user-friendly.

---

## Auto-Updates and Batch Installs

Version 2.0 introduces automatic app updates — a highly requested feature from the community. Users can now enable automatic checking and installation of updates, or disable it if they prefer manual control.

The new client can also download and install multiple apps simultaneously, a quality-of-life improvement for users who frequently install collections of apps. The developers have also removed the pull-to-refresh gesture from app screens, acknowledging that auto-updates make it redundant.

---

## Availability

The new F-Droid client is rolling out in stages over two weeks. Users who want the update immediately can download it from the versions page on F-Droid's website. The default installer on the main site will be updated as the rollout progresses.
