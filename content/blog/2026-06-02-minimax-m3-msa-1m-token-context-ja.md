# MiniMax M3発表：1Mトークン対応スパース注意機構とネイティブ画像・ビデオ入力

2026年6月1日、MiniMax社は新型LLM「MiniMax M3」を正式に公開した。M3はMSA（MiniMax Sparse Attention）と呼ばれる新しいスパース注意機構を採用し、1M（100万）トークンのコンテキストウィンドウ，实现了画像とビデオのネイティブ入力対応。APIはすでに公開済み，重みと技術報告書は10日以内の公開を計画している。

---

## 背景：長文脈LLM市場の競争激化

2026年上半年、LLM市場ではコンテキスト長の競争が激烈化している。Anthropicが200Kコンテキストを標準化した後、GoogleはGemini 2.0 Flashで1Mトークンをサポートし、OpenAIはo3モデルで200Kを提供している。MetaのLlama 4も長文脈対応を強化した。この竞争中，M3が登場した。

---

## MSAアーキテクチャ：計算量の壁に挑む

フルアテンション機構は計算量がシーケンス長の二乗に比例する。1Mトークンでは処理が非現実的になる。MSAは三つの要素でこれ，挑む：

1. **Local Window Attention**：近傍512～1024トークンとの注意を計算し局所文脈を理解する

2. **Global Memory Attention**：シーケンス全体から重要なキーを選択的にメモりに配置し長い距離の依存関係を捕获する

3. **Learned Covariance Correction Branch**：新規導入の枝分かれ機構で，スパース化による情報損失を自動的に補正する

これらにより計算量はO(N log N)程度に削減され，フルアテンションと同等の精度が維持される。

## 1Mトークンコンテキストの実用例

**大規模コードベース理解**：リポジトリ全体を单一プロンプトに読み込みファイル間依存関係を单一モデルで分析できる

**マルチドキュメント調査**：市場調査や学術論文を单一プロンプトで処理しPDF間参照を持つ質問の回答精度が向上する

**長期対話管理**：エージェントが長い対話履歴全体を保持し以前的会话の内容を自然に参照できる

## オープンウェイトモデルとしての公開

M3はオープンウェイトモデルである。 фрон tierレベルのコーディング性能と1Mトークンウィンドウ，ネイティブマルチモーダル入力を单アーキテクチャで組み合わせた点は業界初とされる。

利用可能なエンドポイント：
- **MiniMax Code**：Coding特化
- **MiniMax Token Plan**：Token-Based従量課金
- **MiniMax API**：汎用API

重みと技術報告書は10日以内に公開予定である。
