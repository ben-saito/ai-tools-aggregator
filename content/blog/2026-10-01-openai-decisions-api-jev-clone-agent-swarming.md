# OpenAI Launches Decisions API, a "Jev Clone" for Fast Agent Decision-Making

OpenAI has launched a new API designed to help AI agents make decisions quickly and cheaply, a approach that mirrors TypeSafe AI's Jev model released earlier this month. Called the Decisions API, the new offering represents OpenAI's entry into a emerging category of lightweight, fast AI models purpose-built for software agents.

---

## Copying the Jev Approach for Agent Swarming

The Decisions API provides functionality similar to Jev, a model released by TypeSafe AI that is explicitly designed for software agents. According to OpenAI CEO Sam Altman, the API gives the lab's Luna model a predefined set of choices, allowing it to focus on specific decisions rather than general reasoning.

"By focusing the model on that choice, we can make it extremely fast while keeping capabilities like image understanding, broad language support, and other features," Altman explained at the announcement.

The API addresses a fundamental limitation of large language models: they are comparatively slow and expensive for many software tasks. By narrowing the scope to decision-making, OpenAI can optimize for speed and cost while maintaining useful capabilities.

---

## System One Compatibility and the Future of AI Models

Altman suggested OpenAI's interest in decision-focused AI could be "a sign that building in a System One compatible way is the future." System One is TypeSafe AI's term for architecture that prioritizes rapid, focused inference over broad general capability.

The subtext is that LLMs as currently designed are not always the right solution for software agents. Decision APIs like Jev and OpenAI's new offering represent a different approach: specialized models optimized for the specific task of choosing among predefined options quickly.

OpenAI's entry into this space is not surprising. Several startups are already rolling out similar models, and OpenAI will not be the last tech giant to productize decision-focused AI for agents.

---

## Synthetic Data as Competitive Moat

TypeSafe AI has emphasized that its competitive advantage lies in the synthetic data it creates to generate statistically useful outputs. This approach allows the company to train decision-focused models without relying on traditional web-scraped data.

OpenAI's Decisions API appears to take a similar approach, focusing on fast, cheap intelligence that can be deployed at scale within software workflows.

The emergence of decision-focused AI models represents a shift in how frontier labs are thinking about agent infrastructure. Rather than building general-purpose models that attempt to handle every task, there is growing interest in specialized models optimized for specific agent behaviors.
