# Google Announces Experimental "CC" AI Agent for Families

Google has announced an experimental AI agent internally called "CC" designed for family use, allowing multiple family members to share context and delegate tasks across the household. The agent can coordinate schedules, help with planning, and manage shared to-do lists across family members with different permissions and access levels.

---

## What CC Does

Unlike a personal assistant that serves one user, CC is designed to be a household-level agent. Family members can each connect their accounts and contribute information — calendars, preferences, tasks — and the agent coordinates across those inputs. A parent might ask the agent to plan a weekend trip that works around the kids' soccer schedules, and the agent can access all connected accounts to find available times.

The system supports different permission levels, so parents can set boundaries around what the agent can do or see for children.

---

## Privacy and Data Sharing

Google says the agent only accesses data that family members explicitly connect, and that all processing happens within the family's shared environment. The company has published a technical overview describing how context isolation works between different family members' data streams.

The experimental launch is limited to a small group of Google account families.
