# Anthropic Gives Claude Shared Memory Across Chat and Cowork Apps

Anthropic is rolling out a shared memory feature for Claude, its flagship AI assistant, allowing the model to retain information across conversations and across different surfaces — including the Claude chat interface and the Claude Coworker desktop application. The update means users will no longer need to repeatedly brief Claude on their projects, preferences, and ongoing work context.

---

## Beyond Per-Session Context

Traditional AI assistants treat each conversation as an isolated interaction. Even when you share context early in a conversation, that information disappears once the session ends. Claude's new shared memory changes this fundamental dynamic.

Now, when you tell Claude about a project you're working on, a preference you have, or a piece of context that's relevant to your work, Claude can store that information and apply it in future conversations — whether those happen in the chat interface, the Coworker app, or both.

"Anthropic is giving Claude a shared memory across chat and Cowork, so users no longer have to repeatedly brief the AI on projects, preferences, and other context," TechCrunch reported.

---

## What Claude Remembers

The memory feature isn't just passive storage. Anthropic is also exposing what Claude has retained, giving users visibility into the assistant's understanding of them. Users can read, edit, or delete memories — maintaining control over what Claude knows about them.

This approach balances the utility of persistent memory against legitimate privacy concerns. Users aren't forced to have Claude remember things; they can review and modify what's stored at any time.

---

## Implications for AI-Assisted Work

The ability to maintain context across sessions represents a significant step toward AI assistants that genuinely augment human productivity over the long term. Current assistants can be incredibly useful within a single conversation, but they struggle with tasks that span days, weeks, or longer time horizons.

With shared memory, Claude can track the evolution of a project, recall your communication style preferences, and build up institutional knowledge about the work you do together. This could make Claude more valuable for knowledge workers who use AI assistance as a regular part of their workflow.

---

## Competition and AI Memory

Anthropic isn't alone in exploring persistent memory for AI assistants. OpenAI has discussed similar capabilities for ChatGPT, and other companies are investing in making their AI systems more stateful. The memory arms race reflects a broader industry recognition that AI assistants need to do more than respond to individual prompts — they need to function as ongoing collaborators.

What distinguishes Anthropic's approach is the transparency: giving users explicit visibility and control over what's remembered. As AI memory becomes more prevalent, questions about data handling, privacy, and user autonomy will become increasingly important.

---

## Developer Considerations

For developers building on Claude's API, the memory feature introduces new possibilities for creating AI applications that maintain state over longer periods. An AI coding assistant, for example, could remember your codebase's architecture and coding conventions. A writing assistant could recall your editorial preferences and style guide.

The feature also raises questions about context window management and cost optimization. Developers will need to think about how to leverage memory effectively without accumulating too much context in any given conversation.
