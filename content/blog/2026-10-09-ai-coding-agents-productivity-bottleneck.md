# Study: AI Coding Agents Generate More Code but Don't Increase Software Output

---

A new study of actual coding practices across hundreds of firms reveals that while AI coding assistants and agents can generate large amounts of code efficiently, human code review creates a significant bottleneck that prevents actual productivity gains.

The study found that efficiency increases during the coding phase are "absorbed by downstream constraints in the production process." Specifically, the code review process significantly increases in length, pull requests are more likely to require revisions, and reviewers leave more comments on AI-generated code.

The findings challenge the prevailing narrative that AI coding tools will dramatically increase software output and reduce employment in the tech sector. Instead, the research suggests that human oversight remains essential for ensuring code quality and correctness.

"We're seeing that AI can generate code very quickly, but the human review step hasn't changed," the researchers noted. "The bottleneck has simply shifted from writing code to reviewing it."

The study examined data from hundreds of firms across various industries, finding "little evidence that firms increase software output or reduce employment" through AI coding tools. This suggests that while individual developers may benefit from AI assistants, organizational productivity gains remain elusive.

These findings have implications for companies investing heavily in AI coding tools and agents, suggesting that realizing the full productivity potential of these tools may require rethinking development workflows and the role of human reviewers.

## Key Points

- Study across hundreds of firms shows AI coding agents don't increase software output
- Human code review creates a "bottleneck" that absorbs efficiency gains
- Pull requests require more revisions and comments for AI-generated code
- Findings challenge narratives about AI replacing software development jobs
