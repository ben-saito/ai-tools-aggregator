# Hark Previews Browser Use Agent That Completes Tasks Autonomously

Hark has released a preview of its browser use agent that navigates websites and completes tasks autonomously. The company claims the agent is faster and cheaper than competing browser automation tools that rely on existing AI models.

---

## How it works

The Hark agent takes a natural language instruction and then controls a real browser to complete the task end-to-end. This contrasts with simpler automation tools that can only execute predefined actions. According to Hark, the agent can handle multi-step workflows like booking appointments, filling forms, and comparing products across sites.

---

## Competitive landscape

Browser use agents have become a key battleground in the agent space. Several startups and large labs are building similar capabilities. Hark's differentiation claim is speed and cost: the company says its agent completes tasks in less time and at lower API cost than alternatives.

The full product details and pricing were not disclosed in the preview announcement.
