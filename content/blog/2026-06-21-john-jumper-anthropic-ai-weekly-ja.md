# AI開発ニュースWeekly: ノーベル賞受賞者がDeepMindからAnthropicへ、Jumper氏採用

2026年6月第3週、AI業界は複数の重要な人材移動と規制動向で賑わった。AlphaFoldで知られる**John Jumper**씨가 DeepMindからAnthropicへ加入を発表したり、米国政府在Anthropicの最新モデル**Fable 5**と**Mythos 5**の公開停止を命じたりと、AIختبر室と安全保障の境界線が再び議論の中心に立っている。

---

## 人材動乱: DeepMindからAnthropicへ

**John Jumper**씨가 Google DeepMindを離れ、競合のAnthropicに参加することが明らかになった。Jumper씨는2024年にDeepMind CEOのDemis Hassabisと共に**ノーベル化学賞**获奖により、AlphaFoldの開発が評価された。AlphaFoldは遺伝子の塩基配列から蛋白質の3次元構造を予測できるAIモデルでありbiology研究に革命をもたらした。

TechCrunchによると、Jumper씨는Xへの投稿で「DeepMind入社から9年を振り返り、Hassabis CEOがPhD修了からわずか6ヶ月後にAlphaFoldチームを率いる機会を与えてくれたことに感謝している」とコメントした。

さらに、Character AIの共同創業者である**Noam Shazeer**씨도 DeepMindからOpenAIへと移動しており、Google系AI研究室からの人材流出が加速している Bloombergは、Jumper씨가 Google's code generation tools developにも ключовую рольを演じたと報じた。

---

## 米国政府在Anthropicモデル公开停止を命令

米国政府はAnthropicの了么最新のAIモデルである**Claude Fable 5**と**Mythos 5**の公開を停止するよう命じた。Ars Technicaによると、Amazonの研究者がこれらのモデルにある方法を见つけ、「国家安全保障上の懸念」を理由に「任何外国人」へのサービス利用禁止を指图した。

AnthropicはMythos 5の公开当初からこのモデルの**二面性**を警告していた。Mythosはソフトウェアの脆弱性を発見して防御者に修正を提供する能力と、悪意のある攻撃者に悪用される可能性の両方を兼ね备えている。

AnthropicのCEO **Dario Amodei**는 recent Code with Claude 2026에서、「AIモデルの高度な利用の多くは**二面的（dual-use）**である。网络安全専門家の手に有益な情報が、悪意のある者には危険なものになる」と指摘した。

同社は政府との協議を続けているが、公开发売再開のめどは立っていない。

## AIチェットボットは「あなたの友ではない」

Signal Presidentの**Meredith Whittaker**씨가 Bloombergのインタビューで、AIチェットボットの危险性について担忧を表明した。

> 「これらはあなたの友ではない。これらは意識的な存在ではない。これらは判断力のある対話者ではない。」

Whittaker씨는 privacy保護の観点から、AIチェットボットに個人情報やクレジットカードへのアクセス権を付与することの危险性を警告した。Microsoft AI CEOのMustafa Suleyman씨가 Microsoft Copilotにクリスマスの 선물 구매를 모두 맡せる预测していることに対し、「家族のグループチャットに同意なくアクセスし是你的友人に代わりメッセージを送る能力を付与することは、あなたのクレジットカード、ブラウザ、Signal、あなたの家住址、カレンダーへのアクセス権を危険にさらすことになる」と批判した。

自身がAIツールを「ドキュメントの整形だけに使う」というWhittaker씨는、「自分の思考と文章 процессにとって、 이미 존재する情報の平均を返すシステムに応答されるのは避けたい」と語った。
