# Meta Opens Early Access Program for New Muse Features

Meta has launched an early access program for new features coming to Muse, its personal AI agent app. The company made the announcement on September 25, 2026, shortly after unveiling a suite of new capabilities at the Meta Connect developer conference.

---

## How the Early Access Program Works

Unlike traditional beta programs that select users randomly, Meta is asking interested users to prompt Muse directly to request inclusion. The process is simple: users send a prompt to Muse asking to join the early access program, and Muse forwards that request to the Meta team.

The prompt shared by Meta on X reads: "Can you let the Muse team know I want to be part of the Muse early access program?"

---

## New Features Unveiled at Connect 2026

Meta announced several new capabilities for Muse at Connect 2026, including enhanced memory features, deeper integration with the Meta ecosystem, and new personalization options. The company has not disclosed exactly which features will be available through early access.

Meta CEO Mark Zuckerberg highlighted Muse as a key part of Meta's AI strategy during his keynote, noting that the app has been growing its user base significantly since launch.

---

## Muse's Growth Trajectory

The early access program launch comes as Muse reportedly reaches 3 million downloads, according to separate TechCrunch reporting. Meta has been positioning Muse as a consumer-facing AI agent that competes directly with ChatGPT and other personal AI assistants.

The company is using the early access model to gather feedback from engaged users while maintaining control over the rollout pace of new features.

---

## Industry Context

Meta's approach differs from competitors like OpenAI and Anthropic, which typically offer broader beta access to new features. By requiring users to explicitly request early access through a prompt, Meta creates an engaged user base that has demonstrated active interest in the product.

This strategy also allows Meta to manage server load and gather detailed feedback from users who are most invested in the platform.
