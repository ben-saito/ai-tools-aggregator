# AI Coding Agents Generate More Code, But Human Review Creates Bottleneck

---

A new study finds that while AI coding agents dramatically increase the amount of code generated, the efficiency gains are largely absorbed by human review processes that become the limiting factor on overall productivity.

## The Productivity Paradox

AI coding assistants and agents have proven remarkably efficient at generating large volumes of functional code. However, developers using these tools quickly learn not to trust the output without careful review. The new research quantifies what many engineers have observed anecdotally: coding efficiency improvements from AI agents get "absorbed" by human review bottlenecks.

## Human-in-the-Loop Remains Essential

Despite advances in AI code generation, human developers continue to serve as the critical verification layer. Code review catches errors, identifies security vulnerabilities, and ensures alignment with project requirements — tasks where AI still requires supervision.

## Implications for Development Teams

The findings suggest that organizations deploying AI coding agents may not see proportional increases in overall software output. Instead, the bottleneck simply shifts from code generation to code review. Teams may need to rethink their review processes or accept different quality/delivery tradeoffs when heavily relying on AI-generated code.

## The Quality Question

Beyond productivity metrics, there are ongoing concerns about the quality and maintainability of AI-generated code. While agents can produce syntactically correct code that passes tests, questions remain about whether the code embodies good design practices and whether it can be effectively maintained over time.
