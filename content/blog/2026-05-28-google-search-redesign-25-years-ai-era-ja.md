# Google、AIで検索ボックスを25年ぶりに刷新——Llama以降の検索結果が大きく変わる可能性

25年間もの間、Googleの検索ボックスは細い白い長方形というほぼ変わらぬ姿を維持してきた。しかし2026年のGoogle I/Oで、同社は検索体験の根幹をなすこのインフラを大胆に再設計し、多モーダルAI検索的时代へと踏み出す発表した。AI OverviewsとAI Modeの統合、ファイル・画像・動画的直接入力、Gemini 3.5 Flashによる高速推理、信息エージェントの導入など、検索のパラダイムシフトに関する主要動向をまとめる。

---

## 検索ボックス刷新の衝撃：25年ぶりのUI改革

GoogleはI/O 2026において、同社史上最重要なUI изменениеの1つとして搜索ボックスを再設計すると発表した。、従来のキーワード入力欄が、動的に拡張する会話型インターフェースへと生まれ変わる。

**主な変更点：**

- **多モーダル入力の統合**：テキストに加え、画像、PDF、動画、Chromeタブのコンテンツを検索ボックスに直接ドラッグ＆ドロップ可能に
- **クエリサジェスションの高度化**：単純なオートコンプリートではなく、複雑なクエリ構成をAIが支援
- **AI Overviews × AI Modeのシームレス統合**：兩者を分けない единый search flowの導入

この変更は単なる外観の問題ではない。GoogleのSearch VPであるLiz Reid氏が「デビューから25年以上経過した検索ボックスにとって最大のアップグレード」と表現するように、検索ボックスはGoogleの収益の源泉そのものであり、その設計思想の根幹的な転換点在まれる。従来の「短く簡潔なキーワード入力」という旧来的な相互作用モデルから、ユーザーが深い問いかけを自然言語で表現する新しいSearch Experienceへの移行を示している。

## データで見える検索行動の急速な変化

Googleが共有した usage data は、検索におけるユーザー行動が急速にAI駆動型に変化つつあることを裏付けている。

- **AI Mode**： американ本土向に2025年にローンチ后就、定期ユーザー数1億人を突破。クエリ数は四半期ごとに倍増趋势
- **AI Overviews**：月間2.5億人以上のユーザーにリーチ
- **トークン処理量**：月間3.2クアドラニオン（約7年前の7倍）に達する見込み
- **2026年設備投資**：約1800〜1900億ドル（4年前の約6倍）を予定

Sundar Pichai CEOは「ユーザーは検索をより多く使用している 특히、AI機能を活用するユーザーは検索使用量そのものが増加している」と陈述し、AI機能がtraditional searchを侵食するのではなく、相乗効果を生み出しているとの見方を強調。Pichaiは「検索は世界上で最も使用されているAI製品」だと述べ、Googleの全社的なAI戦略が検索を中核に据えていることを明确にした。

## Gemini 3.5 Flash：検索向けAIモデルの高性能化

这次の搜索改革の裏侧には、新しく発表された **Gemini 3.5 Flash** が控えている。Googleによると、このモデルは前辈モデルのGemini 3.1 Pro比起来 Virtually 全てのが benchmark で高性能化し、的情况下 four times fasterに出力トークンを生成するという。

この速度向上は検索において重要である。会話型AI搜索体験において、レスポンスの遅延は致命的な用户体验の低下につながる。高品質与低レイテンシを組み合わせることで、Googleは「、従来型のキーワード検索相当的Instant感」を維持しながら、大幅に高度なAI検索体験を提供することを目指している。

## 生成UIと情報エージェントの幕開け

Googleが「生成UI」と呼ぶ新技術 также導入される。これは搜索Dynamicallyにカスタムウィジェット、インタラクティブなビジュアライゼーション、甚至はミニアプリ」を实时生成できる機能で、ユーザーの具体的な問いに個別化された回答を提供する。

具体例として、「ブラックホールが時空にどのような影響を与えるか」と質問すると、AI Overview内でインタラクティブなビジュアライゼーションが生成され、フォローアップの質問に対してリアルタイムに 새로운 시각 자료が動的に生成される。これはGemini 3.5 Flashの上でGoogle DeepMindチームが構築した「新型リアルタイムコード生成システム」により実現される。

さらに、情報を сайтаの範囲で継続的にモニタリングする「情報エージェント」も導入される。例えば金融市场の動きを特定の浏览条件に基づいて追跡するエージェントを搜索内で設定でき、条件に合致した時点で加入受け取れる。

## PEFT評価の新視点：Stability-Plasticity Dilemma

一方、arXiv（5月27日）では **PEFT-Arena** と呼ばれる新しい評価フレームワークが注目を集めた。Parameter-Efficient Fine-Tuning（PEFT）は大規模言語モデルの適応において標準的なアプローチとなりつつあるが、従来の評価は下流タスクの正確度に偏重し、事前学習済み能力の維持度合いを見落とす傾向があった。

この研究では、PEFT手法の評価に **stability-plasticity dilemma** の视点を導入することを提唱している。plasticity（新機能の獲得能力）と stability（事前学習済み能力の維持）のバランスこそがPEFT手法の真の実力を測る指标になるとし、SFTやLoRAなどの的手法比較でその有効性を実証している。これは実運用においてモデルが新しいタスク适应的同时に、不要なCapabilityの涌现を起こさないことを保证する上で重要である。

## 自己改善するLLM：双方向Evolutionary Search

同样に5月27日のarXivには **Self-Improving Language Models with Bidirectional Evolutionary Search** も投稿されている。

従来のbest-of-N samplingやtree searchなどの自主改善手法には2つの根本的な制約があった分别是、（1）Sparse検証信号にしか基づかない、（2）推論時と训练時の乖離が大きいという問題である。本研究では雙方向Evolutionary Searchを提案し、事前学習済みモデルの知識を活用しながら推論時の探索を改善する枠組みを構築。论理的にも実践的にも，自己改善LLMの実現に新たな道を拓いている。

## スケーラブル監督：人間とAIの能力差への対策

**Calibrating Conservatism for Scalable Oversight** も同日投稿され、agentic AIシステムにおける根本的な制御問題を扱った。自主的な計画と長期環境互动能力を持つAIシステムが人間の能力を超える可能性がある場合、人間が意味のある监督を維持する 방법은何か。

 기존의スケーラブル監督アプローチは複雑なassumptionに依存し、実用的な実装が困難であることが多い。この研究では、**conservatism**：より広い是不可能的解空间を容認する留保さを資本vs性能のトレードオフを体系的にキャリブレーションする手法を提案し、本当の意味でのscalable oversightの実現に近づいている。

## VentureBeatが伝えたClaude Code vs Goose問題

もう1つ值得注意的是、VentureBeatが报じた **Claude Code costs up to $200 a month. Goose does the same thing for free** という论稿である。

_block_ 开发したAI coding assistant「Goose」は、Claude Codeと比較して遜色ない機能を 무료로 제공한다的点に大きく关注が集まっている。OllamaなどのローカルLLMと組み合わせることで、APIキーやクラウドサービスに依存せずに複雑なコーディングタスクを実行できる。

论的としては、 _$200per月の时代が終わりに址している可能性_ が指摘されている。支持者は「コードがクラウドに残ることへの懸念」からローカルLLMを重視する開発ontribusi以来、特に privacy-conscious な环境下で注目されています。ただし、モデル品質、コンテキストウィンドウ、速度 инструментов maturityにおいて商用手 Melvinとの间には 아직gapが存在することも事実である。
