# Anthropic Releases MHS Hardware Standard for AI Agent Control of Physical Devices

Anthropic has developed a new hardware standard called Model Host Standard (MHS) that enables AI agents to control physical world devices. This standardized driver interface allows seamless communication between different hardware devices without requiring custom translator software.

---

## Purpose: Improving Hardware Interoperability

Currently, AI agents coordinating multiple physical devices in scientific experiments or industrial settings require customized software integrations for each device. MHS provides a common interface and data sharing format between devices, enabling direct communication over a network without bespoke translator programs.

The effort is currently available as a research preview, particularly helping scientists streamline the process of integrating diverse lab equipment.

---

## Scaling AI Agents Through Standardization

MHS creates a standardized layer between AI agents and physical space, enabling device control regardless of type using the same prompts. This dramatically expands AI agent applicability from digital spaces to industrial equipment and research apparatus.

MHS will be published as an open specification, with calls for participation from hardware manufacturers and research institutions.
