# Anthropicのグローバル展開とAI経済成長率2000%: 開発者向けAI開発週報

2026年6月上旬、Anthropicがグローバル展開を加速させている。Series Hで65億ドルの資金調達（965億ドル企業評価額）、S-1申請の提出、Project Glasswingの150組織・15カ国以上への拡大、そして米兰・ソウルオフィスの開設だ。一方、AI経済の米国における成長率は年間2000%に達しており、Compute集約的なAI企業の経済構造が改めて注目されている。

---

## Anthropic、Series Hで65億ドルの資金調達とS-1申請提出

Anthropicは2026年5月28日、Series Hラウンドで65億ドルの資金調達を実施した。企業評価額は965億ドル（ポストマネーベース）で、これはAI史上最額の資金調達の一つとなった。

**主なポイント：**

- **IPOへの道筋**：Anthropicは6月1日にSEC宛てに機密保護のdraft S-1を提出した。Daniela Amodei（CPO）は「AIは過大評価されているという声が出ているが、我々は長期的に見ている」とコメント
- **資金使途**：推論コスト、研究開発、およびグローバル展開の加速に充てられる
- **企業評価額の背景**：965億ドルという評価額は、OpenAIの1500億ドル評価額に次ぐ規模

Daniela Amodei氏はTechCrunchの取材に対し、「AI企业对市場は合理的な判断をしている。短期的波动に惑わされずに、長期的な価値創造を目指している」と強調した。

**開発者視点での意義：**

Claude Enterpriseの顧客には、Google CloudのVertex AI、Microsoft Foundry、Salesforce、NVIDIA、GitHub Copilotなどが含まれる。IPOが実現すれば、Claude Code Enterpriseの企業向け展開がさらに加速することが予想される。

## Project Glasswing: 150組織・15カ国以上への拡大

AnthropicはProject Glasswingを約150の新規組織に拡大している。対象は15カ国以上で、これは企業向けAIアシスタントの国際的普及加速を示している。

**Project Glasswingの詳細：**

- **対象**：大企業向けのAIアシスタント統合サービス
- **規模**：150新規組織、15カ国以上
- **背景**：企業のAI導入が「実験段階」から「本格導入段階」へと移行

GlasswingはClaudeを企業の既存のワークフローに統合するサービスであり、SaaS型での提供が基本。Microsoft 365やGoogle Workspaceとの接続が既にサポートされている。

**開発者にとってのポイント：**

企業向けAI統合の需要が高まっている。MCP（Model Context Protocol）を使ったClaude Desktop agent和企业向けシステムとの接続が、标准的な統合パターンとして定着しつつある。

## Anthropic、欧州とアジアに新規オフィス：ミラノとソウル

Anthropicはイタリア・ミラノと韓国・ソウルに新規オフィスを開設する計画を明らかにした。

**ミラノオフィス（European expansion）：**

- イタリア企業、研究者、開発者向けサポート強化
- GDPR対応と欧州市場向けのデータ主権確保
- EUのAI規制（AI Act）への適合

**ソウルオフィス（Asian expansion）：**

- Korea Representative DirectorにKiYoung Choi氏を任命
- アジア太平洋地域の企業顧客向けアプローチ強化
- Samsung、SK、Hynixなどの韓国大手テック企業とのパートナーシップ構築が期待

これはOpenAI、Googleに続く形でAnthropicもアジア・欧州市場への本格参入を進めるものであり、AI企業のグローバル競争が熾烈化している。

## AI経済成長率2000%: Import AIが語るAI産業の構造変化

Jack Clark氏編集のImport AIニュースレター最新号（Issue 459）は、米国のAI経済が年間2000%成長していることを報じた。

**经济增长の背景：**

- **直接測定の困難さ**：従来のGDP統計ではAIの貢献が適切に測定されていない
- **Virginia大学とAnthropicの共同研究**：経済学者たちがAI経済の実態分析を実施
- **Bank of Canadaの報告書**：AIが金融セクターに与える影響を分析

**AI企業のコスト構造：**

- LLM推論コストは依然として高額（1ユーザーあたり月額20ドル以上）
- GPUクラスターの拡充が投資家の補助金に依存
- 価格を上げればユーザーは離れ、価格を下げれば事業が持続不可能

これは「Tokenpocalypse」（トークンパイロキャルプス）問題と呼ばれ、AI企業のIPO成功に向けて解決策が求められている。

**AI oversight（AI監視）の困難さ：**

Import AIはAIシステムを監督することの困難さも指摘している。AIの行動範囲拡大に追いつく監視体制の構築が課題となる。

## データセンター建設ラッシュ: AirTrunkがインドに300億ドル投資

オーストラリアのナイト事業者がAirTrunkは、インドに300億ドル（约5兆円）を投資し、5GW規模のAIデータセンターを建設する計画を明らかにした。

**計画の概要：**

- **投資額**：300億ドル（约5兆円）
- **規模**：5GW（ギガワット）容量
- **期間**：今後数年間で段階的に建設
- **背景**：インドのAIコンピューティング需要の爆発的成長

5GWは、大型都市の電力消费量に匹敵する規模であり、AIのための専門的インフラ投資が加速していることを示している。

**他の投資事例：**

- MicrosoftはSpaceXに毎月9.2億ドルを支払い、衛星ベースのAI Computeを確保
- Googleは年間1000億ドル以上をAIインフラに投資
- AWS、Azure、GCPすべてがAI向けデータセンター建設を加速
