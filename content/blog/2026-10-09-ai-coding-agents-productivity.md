# AI Coding Agents Generate More Code, But Not More Software

---

A new study from Harvard researchers finds that AI coding tools dramatically increase the amount of code produced — but fail to boost overall software output or reduce engineering headcount. The reason: human code review becomes the new bottleneck.

The study, conducted by Fiona Chen and James Stratton at Harvard, analyzed 300 million work events across over 700,000 employees at more than 700 software development firms from 2021 through March 2026. The data came from Jellyfish, which tracks granular engineering metrics, combined with GitHub activity analysis.

## The Numbers: 30% More Code, Same Output

The results are stark on their face. Firms introducing AI coding agents saw a 30% increase in total lines of code generated and a 20% increase in code submission frequency. The volume of code being written — measured by commits and pull requests — rose substantially.

Yet the researchers found "little evidence that firms increase software output or reduce employment" as a result. The efficiency gains from faster code generation were almost entirely absorbed by downstream constraints.

## The Review Bottleneck

The critical constraint is code review. While AI coding agents dramatically speed up the initial code generation phase, human reviewers must still evaluate every piece of AI-generated code. The study found that:

- Code review processes increased significantly in length after AI tool adoption
- Pull requests were more likely to require revisions
- Reviewers left substantially more comments on AI-generated code

This means the human review step, which cannot be easily accelerated, becomes the limiting factor on overall productivity. You can generate code 30% faster, but if reviews still take the same amount of time, the net gain is close to zero.

## What the Data Can't Tell Us

The study's timeframe — 2021 through early 2026 — captures only the early stages of AI coding adoption. It's possible that as both AI tools and developer workflows evolve, the review bottleneck will ease. Teams may develop better practices for reviewing AI-generated code, or AI systems may improve to the point where less review is needed.

The research also doesn't capture longer-term effects on software quality, maintainability, or developer experience. A team that produces the same amount of code with less total human effort may still be better or worse off depending on how that code ages.
