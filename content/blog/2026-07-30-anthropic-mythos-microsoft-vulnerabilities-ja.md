# Anthropic Mythos Model Exposes Microsoft Vulnerabilities at Unprecedented Pace

---

## AI-Powered Security Testing Reveals Scale of Vulnerability Discovery

Anthropic's AI model Mythos is finding security vulnerabilities in Microsoft code faster than Microsoft's engineers can patch them, according to a ProPublica report cited by Ars Technica. Microsoft engineers have been using Claude Mythos Preview -- Anthropic's model specifically designed for security research -- to surface weaknesses across the company's software portfolio.

The situation has reached a point where Microsoft engineers described being in "a mad dash" to close the gap between vulnerability discovery and patching. According to a recording viewed by ProPublica, a Microsoft engineering manager confirmed that Mythos was "living up to the hype" Anthropic claimed for it.

---

## Critical Numbers: 90 Critical Bugs in SharePoint Alone

In April 2026, Mythos uncovered 90 "critical" bugs and 141 "important" bugs in SharePoint, Microsoft's widely used collaboration software. The volume of discoveries created a significant backlog, with engineers imploring their teams to "drive those down" in the roughly two weeks before a planned release.

One engineer on the call summarized the predicament: if the vulnerable code was released on June 1, by June 2 adversaries would have access to those same vulnerabilities.

---

## Implications for AI-Assisted Security

The Mythos case represents a concrete example of AI-accelerated vulnerability research moving faster than traditional security operations can respond. For developers, this highlights a coming challenge: AI systems that can thoroughly audit codebases will force security teams to adopt AI-assisted patching workflows or risk falling further behind the discovery curve.

The dynamic also raises questions about model access policies. Anthropic provided Microsoft with early access to a security-focused model variant, suggesting that frontier AI safety capabilities may increasingly be deployed in offensive security contexts.
