# Supabase Customers Exposing User Data Through AI Vibe-Coded Apps

---

## Security Researchers Find Widespread Data Misconfigurations on Supabase Platform

Security researchers at UpGuard have discovered that a significant number of applications built on Supabase, the open-source Firebase alternative, are publicly exposing sensitive user data due to improper security configurations. The findings highlight a new wave of data breaches linked to AI-generated and "vibe-coded" applications that prioritize rapid development over security best practices.

Supabase reached a $10 billion valuation earlier this year, buoyed by the rise of developers hosting AI-built applications on its platform. However, the company has faced mounting criticism over how it handles user security as the influx of AI-generated code has increased.

---

## The Vibe-Coding Security Problem

The boom in AI-assisted development has made it easier than ever to build and deploy applications quickly. Tools can generate functional websites and apps in minutes, but the resulting code often lacks proper security configurations. This is particularly problematic when developers use default settings or fail to implement appropriate access controls.

Over the years, countless data breaches have stemmed from improperly configured storage servers, databases, and websites. Such incidents have led to leaks of sensitive information including military emails, immigration records, and medical data. Now, the surge in AI-powered development is fueling a new category of similar breaches.

UpGuard's investigation sought to understand the scale of exposed data across the Supabase platform. The research surfaced publicly accessible names, addresses, phone numbers, and user passwords across multiple applications. While the majority of these exposed datasets appear to be located in the United States, UpGuard notes this is a worldwide problem affecting users globally.

---

## Supabase Platform Response

Supabase has made changes to its platform over the years, including bolstering its security infrastructure and improving user access controls to databases. However, the rapid adoption of AI-assisted development tools has outpaced the company's ability to ensure all customers follow secure deployment practices.

The research underscores a broader challenge facing developers and platforms in the AI era: as application creation becomes more accessible, the responsibility for security configuration increasingly falls on developers who may lack formal training in secure coding practices.

---

## Implications for AI Development Ecosystem

This incident reflects a tension inherent in the democratization of software development through AI tools. While vibe-coding enables rapid prototyping and deployment, the security implications of AI-generated code warrant careful attention from both developers and the platforms hosting their applications.

Organizations using Supabase or similar backend-as-a-service platforms should conduct regular audits of their database access policies and ensure that AI-generated code undergoes security review before deployment.
