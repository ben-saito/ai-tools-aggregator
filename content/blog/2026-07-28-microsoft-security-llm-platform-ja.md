# Microsoft、初めての本格的なセキュリティ特化LLMを発表

Microsoftは7月27日、同社初となるセキュリティ特化の大規模言語モデルと
新しいエージェント型セキュリティプラットフォームの一般提供を開始した。
既存セキュリティ製品より低コストで、競合製品を超える性能を実現したと主張している。
---
## セキュリティLLM市场规模への参入

Microsoft Security Copilot以来、同社はAIを活用したセキュリティ分野への
注力を強化してきた。本次発表は専用モデルによる脅威検出、
インシデント対応、自動修復などを統合的にカバーする
プラットフォーム形態で展開される。

セキュリティ特化LLMの需要は高く、
CrowdStrikeやPalo Alto Networksといった既存プレイヤーも
同様のAI製品を投入している。MicrosoftはAzureインフラとの統合を武器に
エンタープライズ市場の取り込みを狙う。
---
## エージェント型セキュリティ：新世代SOCの愿景

従来のSecurity Operations Center（SOC）はアナリストが手動で脅威を調査していた。
Microsoftの新プラットフォームは、AIエージェントがインシデントを自律的に
調査・封じ込める「エージェント型SOC」を構想している。

エージェントとは人間のアナリストに代わって
ログ分析、因果追跡、修復オペレーションを実行するAIシステムのことで、
MicrosoftはこれをSecurity Copilot基盤上に構築した。
---
## 技術的ポイント：専用モデルとコスト優位性

Microsoftが強調するのは「コスト性能比」だ。
既存のSIG Redmond社製品を置き換える形で、
同等の検出精度を低コストで実現すると主張している。
Azure SentinelやDefender for Endpointユーザーにとっては、
既存Azure環境とのシームレスな連携が利点として挙げられる。

セキュリティLLMの精度評価にはMITRE ATT&CKフレームワークが
使われることが多く、Microsoftも同指標での競合比較データを公開している。
