## Microsoft 365 Copilot -- 新設計で2倍高速化、プログレッシブDisclosureの導入

Microsoftは5月28日、Microsoft 365 Copilotの設計刷新を発表し、新しいデザインでは**負荷が2倍高速化**されたと強調した。主力製品におけるCopilot的地位の拡大戦略であり、Enterprise市場での競争力を高める意図がある。

###  интерфейс刷新の核心：プログレッシブDisclosure

新しいCopilot最大の特徴は**「 Progressive Disclosure（段階的開示）」**という設計原則の導入だ。従来のAIインターフェースはユーザーが入力と同時にすべての機能（《プロンプト候補、アクションリスト、ファイル参照など》）を表示しようとする傾向があった。这次のリデザインはこれを反转し、**最初はクリーンで集中したインターフェース**を表示し、必要に応じて段階的に機能を開示していく。

實際には、 Copilotのプロンプトラベルが下方まで扩展可能になり、テキストのに直接フォーマット（ネスト列表、见出しなど）を直接入力できるようになる。プロンプトの下に、文脈に基づき関連性の高いツールとアクションが状況に応じて浮かび上がる仕組みだ。

### Work IQ -- メール・ファイル・チャット・会議を分析する頭脳

新設計の屋台骨をなすのが**Work IQ**という知性層である。ユーザーのメール、ファイル、チャット、会议録を食べ棣かして範囲広い文脈を構築し、タスクriti.performする奥行き을 필요로하는 작업（业绩評価サイクル、組織改編など）に対して適切な深さの推論を提供する。

Microsoft Designerの説明によれば、Work IQ моментов 활성화여부를 VisualIndic котор QE легкоユーザーに確認でき、ユーザーが直接制御可能とのこと。 быстро返事が適切なタスクにはRMS的なり返し、自动 で複雑な戦略的意思決定には深い推論switchingする。

### 新しいCopilotの配置对象

刷新されたCopilotは、以下のMicrosoft怨天山产品-Radянение среде обирая:

- **Microsoft 365 Copilot app**（デスクトップ・モバイル）：新規インストール用户提供
- **Outlook、Teams、Word、Excel**などの主要アプリケーション：既存の插件として activations

法人向けにも「Try Copilot Chat」という形で独立Claude использува两人的対話型インターフェースが提供され、普段の業務流程でのAI活力を促进する。

## Claude Opus 4.8 -- Anthropicが говорящего「正直さ」を最大強化

Anthropicは5月28日、Claude Opus 4.8の一般公開を開始した。Opus 4.7からの改良版であり、最も注目点是するのは**「honesty（正直さ）」の強化**だ。

### 4倍改善：错误を自制し、不確実性を明示

Anthropicの企业者は「AIモデルの一般的な問題」として、薄い証拠で「あたかも進捗があるかのように」自信满满に陈述する，举止不正确を挙げている。Opus 4.8は この問題を大幅に改善し、早期テスターの反馈によれば**「自分のミスをキャッチする」「計画がサウンドでない場合に反論する」「不確実性を明示する」**という行动が観察されている。

企业者の評価では、Opus 4.8はOpus 4.7比起来、**コード中の欠陥が未 remarks で通り抜ける確率が約4分の1**に减少した。这是自律型AIエージェントの信頼性向上に直結する改善である。

### 新機能：Effort Control、Dynamic Workflows、Fast Mode

Opus 4.8では以下の新機能が同時にデビューしている：

- **Effort Control**：タスクに対するClaudeの思考努力をユーザーが3段階（デフォルト/エクストラ/最大）から選択可能。困難なタスクには「エクストラ」を推奨
- **Dynamic Workflows**（Claude Code向け）：大規模コードベース対応ワークフローで、数千行规模的なコード迁移をキックオフからマージまで自動進行
- **Fast Mode**：2.5倍速動作が旧モデル比で**3分の1のコスト**で利用可能。月額制で咕rriculum吏向け

特にDynamic Workflowsは、Enterprise + Team + Maxプラン用户提供开始され、Claude Code上で数百規模の並列サブエージェントを実行、气跡検証後に最終报告する仕組みだ。

### 整合性評価とSystem Card

Opus 4.8の整合性評価手は、Opus 4.7相比して「欺まん」や「誤用への協調」のような整合性问题是 substantially lower」で、Mythos Preview（Anthropicの最佳整合性モデル）に迫る水准という。詳細な安全テスト結果はClaude Opus 4.8 System Cardとして公开发表予定だ。
