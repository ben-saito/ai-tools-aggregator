# Figma announces new features to define how agents work on its platform

---

Design platform Figma announced a new Markdown-based editor called **Figma Specs** at its first Config event in India, aiming to provide a definition that both human teams and AI agents can follow when working within a brand's design system. The feature lets users define design language in a simple text format, serving as a centralized reference for design libraries, code libraries, and guidelines. Agents operating within Figma can consult this document to adhere to brand rules while creating with AI.

Figma Specs functions as a standalone file or can coexist within the canvas, letting users reference other Figma elements including those on the canvas, embed FigJam diagrams, and link code layers and designs. The company says this creates a shared source of truth for design intent that bridges the gap between human designers and autonomous agents.

**Agent integration and expandability**

Figma also made its agent-on-canvas feature available to a wider user base over the past week. Given the non-deterministic nature of AI outputs, the company is providing steering tools to guide agents toward more predictable outcomes. Users can ask the agent to turn a design into code or modify parts of the code to iterate on a prototype.

The company announced it is now supporting over 20 new tools with its Model Context Protocol (MCP), including Open Code, Dia, Grok Bot, and Indian AI startup Sarvam. Figma acquired open-source headless CMS Payload last year, and the platform is being integrated with Figma Make for generating dynamic websites and managing content directly. Payload downloads have increased sixfold in the last 12 months.

**Code layers and prototype iteration**

Figma's code layers feature, which adds coding capabilities to designs on canvas for more interactive prototypes, was announced in private beta in June and is now available in public beta. Users can iterate on prototypes by asking the agent to modify code directly or generate code from existing designs.

**Market context**

Figma opened its first India office late last year and says the country is its biggest market by users outside the United States. The platform works with 40% of India's top 100 companies listed on the Bombay Stock Exchange. The Config event in India marks the company's first in the region, reflecting its growing international footprint.
