# Shopify Opens Checkout to Browser-Based AI Agents

Shopify has expanded its WebMCP (Model Context Protocol) support to include checkout functionality, enabling browser-based AI agents to complete purchases on Shopify merchants' storefronts with buyer authorization.

---

## From Browsing to Buying

Previously, AI agents could use WebMCP to browse Shopify storefronts, search inventory, and add items to carts, but the checkout process required manual human intervention. The new update allows agents to transmit saved payment methods and shipping addresses on file, then prompt the human user to authorize the final transaction.

This follows the broader WebMCP standard that several AI assistant developers have adopted, providing a common interface for agents to interact with web services without requiring custom API integrations for each platform.

---

## Implications for Commerce and AI Assistants

The ability for AI agents to complete purchases represents a step toward integrated AI assistant workflows. Rather than switching between a browser and an AI chat interface, users could delegate shopping tasks — comparing prices, checking inventory, applying discount codes — to an agent that completes the transaction end-to-end.

Shopify noted that all transactions still require buyer authorization, meaning the AI cannot spend money without explicit human approval at the payment step. The feature is rolling out to merchants running Shopify's latest platform version.
