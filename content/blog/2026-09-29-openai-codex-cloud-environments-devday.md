# OpenAI Expands Codex with Persistent Cloud Environments and Security Tools

OpenAI announced significant updates to its Codex coding agent at the company's Dev Day event, introducing reusable cloud development environments, a redesigned command-line interface with voice controls, new code review capabilities, and a security-focused product for scanning repositories and preparing fixes.

The most substantial change addresses how cloud development environments function within Codex. Previously, Codex could spin up cloud tasks to execute work remotely, but these environments were temporary and discarded after task completion. The new reusable cloud environments allow developers to maintain persistent development setups that persist across sessions and work across multiple devices, addressing a common friction point in remote development workflows.

The refreshed Codex CLI brings voice controls, enabling developers to issue commands and navigate code through spoken instructions. This voice interface builds on the agentic foundation of Codex, allowing for hands-free interaction during development tasks. OpenAI simultaneously announced a code review tool that integrates directly with the agent workflow, enabling automated analysis of code changes alongside human review.

The security product targets repository scanning and fix preparation, positioning Codex more directly in the enterprise development tooling market where security and compliance considerations shape purchasing decisions. By embedding security scanning within the agent workflow rather than requiring separate tools, OpenAI aims to reduce friction between code development and security review.

These announcements signal OpenAI's intention to position Codex as a comprehensive development environment rather than a standalone coding assistant. The combination of persistent cloud environments, voice-controlled CLI, integrated code review, and security scanning reflects a broader consolidation trend in developer tooling, where AI agents increasingly serve as the orchestration layer for multiple development tasks.
