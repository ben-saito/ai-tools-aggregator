A new study on AI coding agents finds that while these tools increase the amount of code generated, they do not necessarily increase overall software output quality or quantity. The research highlights a critical bottleneck: human code review.

The study, covered by Ars Technica, examined development teams using AI coding assistants across various projects. Researchers found that AI agents successfully increased the volume of code written, but human reviewers spent significantly more time evaluating, testing, and potentially rewriting AI-generated code than they would have spent writing code from scratch.

This "absorption" effect suggests that efficiency gains from AI coding tools may be more limited than their proponents claim. Rather than simply accelerating development, AI coding agents shift work from code writing to code review—a transition that requires new skills and processes.

The findings have implications for development teams evaluating AI coding tools. While individual developers may see productivity gains, organizations must consider the full workflow impact, including how AI-generated code integrates with existing review processes and quality assurance practices.

## Technical Perspective

AI coding agents operate by generating code suggestions based on training data and context. These systems can produce functional code quickly, but the generated code may not always follow best practices, may contain subtle bugs, or may not align with the specific requirements of the project.

The human review bottleneck reflects a fundamental limitation: while AI can generate code faster than humans can write it, human oversight remains essential for ensuring code quality, security, and maintainability. This creates a mismatch where AI accelerates one phase of development while another phase becomes the new constraint.

Teams implementing AI coding tools may need to rethink their workflows, potentially investing in better testing infrastructure, automated code analysis, and review processes that can scale with AI-generated code volume.
