# ChatGPT Now Sends Text Messages via Apple Messages Plugin

OpenAI has launched an Apple Messages plug-in for ChatGPT, allowing users to connect their Messages inbox directly to the chatbot. Once enabled, the plug-in can sort, analyze, and edit messages from ChatGPT. It also works with Codex and ChatGPT Work for professional use cases.

Users can ask ChatGPT to suggest follow-up messages based on recent contacts, draft and send messages on their behalf, or search through message history. OpenAI told Bloomberg the plug-in runs locally on the user's machine and does not create a full index of all messages.

The company warns users to avoid enabling persistent approval, which removes the final chance to review a message before ChatGPT sends it. This privacy consideration comes as OpenAI pushes deeper into mobile assistant integration, competing with Google's Gemini on Android.
