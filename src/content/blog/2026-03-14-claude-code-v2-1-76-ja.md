## 変更点の概要

v2.1.76では、 précédentesバージョン）で報告された問題の修正と、全体的なパフォーマンス改善が実施されている。具体的な変更点については、公式のリリースノートを参照されたい。

前回のリリースで発見された脆弱性に対する修正が含まれている。Claude Codeユーザーはできるだけ早くこのバージョンにアップデートすることが推奨される。

### 安定性の向上

 various stability improvements have been implemented to enhance the overall user experience. These include bug fixes and optimizations that address issues reported by the community.

## アップデート方法

Claude Codeは自動的にアップデートされます。手動でアップデートするには以下のコマンドを実行:

```bash
claude update
```

または、Claude Codeのウェブサイト（claude.com/claude-code）から最新バージョンをダウンロードできます。
