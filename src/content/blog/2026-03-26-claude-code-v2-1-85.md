Claude Code v2.1.85 was released on March 25, 2026, bringing Anthropic Console login support, UI improvements, and various stability enhancements.

## Anthropic Console Login Support

A new **--console flag** has been added to enable direct login to Anthropic Console from the command line. This provides more flexible authentication options beyond traditional environment variable-based credentials.

This feature is particularly valuable for enterprise deployments where centralized authentication management is required.

## Turn Duration Display

A **Show turn duration toggle** has been implemented, allowing users to view execution time for each turn. This helps with performance analysis and identifying bottlenecks during long-running tasks.

Developers can now better understand how much time each step takes in extended coding sessions, enabling more efficient workflow optimization.

## Stability Improvements

Multiple bug fixes and improvements have been implemented:

- **CLI Stability**: Various CLI operation bugs have been fixed for more reliable command execution
- **Voice Improvements**: Voice input-related improvements provide smoother voice interaction
- **Streaming Enhancements**: Real-time output stability has been improved
- **VSCode Extension Fixes**: Various issues in the editor extension have been resolved

These improvements enhance reliability during everyday development workflows.

## Performance Enhancements

Beyond the new features and stability fixes, the following improvements have been made:

- **Startup Memory**: Memory usage at startup has been optimized
- **Session Handling**: Session management efficiency has been improved
- **Navigation**: Codebase navigation is now smoother
- **Multi-seed Support**: Better handling of concurrent multiple version execution
- **Timeout Handling**: More reliable timeout processing

These enhancements provide a smoother development experience overall.
