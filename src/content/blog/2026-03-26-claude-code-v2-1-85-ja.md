Claude Code v2.1.85が2026年3月25日にリリースされた今回は、Anthropic Consoleログインのサポート、UI改善、数多くの安定性向上が含まれている。

## Anthropic Consoleログインサポート

**--consoleフラグ**が 새로追加되었다。これにより、Anthropic Consoleへのログイン命令行から可以直接実行できる。Claude Codeを使用することで、API鍵管理や认证信息の管理がより灵活になった。

この機能はEnterprise环境での展开时に特に有用で、従来の環境変数 기반認証に加え、新しい认证方法が利用可能になった。

## ターン時間表示機能

**Show turn durationトグル**が実装された。これにより、各ターンの実行時間を確認できるようになった。パフォーマンスの分析やボトルネックの特定に 도움이となる。

长时间的タスクを実行する際に、各步骤どの程度时間がかかっているかを把握できるため、より効率的な开发流程の最適化が可能になった。

## 安定性改善

多くのバグ修正と改善が実施されている:

- **CLI安定性**: 各种のCLI操作相关的バグが修正され、より安定したコマンド実行が可能になった
- **Voice機能改善**: 音声入力相关の改善により、よりスムーズな音声协応が可能になった
- **ストリーミング改善**: リアルタイム出力の安定性が向上した
- **VSCode拡張機能改善**: エディタ拡張機能の各种の問題が修正された

これらの改善により、日常的な开发作业における信頼性が向上している。

## パフォーマンス改善

роме上述の機能追加と安定性向上に加え、以下の面で改善が実施されている:

- **スタートアップメモリ**: 起動时のメモリ使用量が优化された
- **セッション処理**: セッション管理の效率が向上した
- **ナビゲーション改善**: コードベース内の导航がよりスムーズになった
- **マルチシード対応**: 複数バージョン同时実行の改善
- **タイムアウト处理**: タイムアウト处理の信頼性向上

これらの改善により、よりスムーズな开发体验が提供されている。
