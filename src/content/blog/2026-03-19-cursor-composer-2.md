Anysphere has announced Composer 2, a new version of its AI-powered code editor Cursor, on March 19, 2026. The company claims Composer 2 achieves frontier-level coding performance.

## Composer 2 Performance

According to Cursor's announcement, Composer 2 delivers "strong results on challenging coding tasks." The new version has been evaluated using Cursor Bench, with particular emphasis on performance in complex coding scenarios.

### Pricing Tiers

Composer 2 offers two pricing tiers:

| Tier | Input Tokens | Output Tokens |
|------|-------------|---------------|
| Standard | $0.50/M | $2.50/M |
| Fast (default) | $1.50/M | $7.50/M |

The Standard tier provides a more economical option, while Fast is set as the default configuration.

## About Cursor

Cursor is an AI-powered code editor built on VS Code by Anysphere. It features code completion, AI chat, and the ability to query entire codebases, and has rapidly gained traction in the developer community from 2024 to 2025.

In late October 2025, Cursor 2.0 was released with significant updates including the Composer feature. Composer 2 represents the next evolution of this functionality.

## Outlook

The release of Composer 2 is expected to further intensify competition among AI-powered coding assistance tools. With updated monthly pricing, developers gain access to more advanced AI assistance capabilities.
