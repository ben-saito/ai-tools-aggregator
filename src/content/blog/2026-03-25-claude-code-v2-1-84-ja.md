Claude Code v2.1.84が2026年3月25日にリリースされた今回は、Managed Settingsの拡張、环境管理向けフックイベント、セキュリティ強化、数多くのバグ修正と改善が含まれている。

## Managed Settingsの強化

**managed-settings.d/ドロップインディレクトリ**が導入された。これにより、部门ごとに独立したポリシーフラグメントをアルファベット順にマージして配置できるようになった。従来は单一的設定ファイルでの管理だったが、チームごとに分工してポリシーを定義できるよになった。

また、**sandbox.failIfUnavailable**設定が追加され、サンドボックスが有効却启动できない场合にエラーで終了する动作が选择可能になった。従来はサンドボックス无しで実行されていたが、セキュリティ要件が严格的になった场合에는明確に失败として扱える。

さらに、**disableDeepLinkRegistration**设置が追加され、claude-cli://プロトコルハンドラの登録を無効化できる。Enterprise环境での展開などで、プロトコルハンドラ的管理が可选となった。

## 环境管理向けフックイベント

**CwdChanged**と**FileChanged**两种のフックイベントが新增了。これらのイベントにより Reactive な环境管理が可能になった。特にdirenvなどのツールとの连携が期待でき、ディレクトリ移动やファイル变更に反应した环境变量的设定自动化ができる。

また、**CLAUDE_CODE_SUBPROCESS_ENV_SCRUB=1**环境变量が導入され、サブプロセス环境からAnthropicおよびクラウドプロバイダー认证情报が削除される。Bashツール、フック、MCP stdioサーバーで実行されるサブプロセス全部に適用され、より安全な実行环境が确保できる。

## ユーザー体验の向上

**トランスクリプト検索機能**が実装された。トランスクリプトモード（Ctrl+O）で/を押すと検索可能出现し、n/Nでマッチを顺に辿れる。過去の会话を большая容量检索する際に便利になった。

**Ctrl+X Ctrl+E**がエ外部エディア开启のエイリアスとして追加された。readline标准的バインディングで、Ctrl+Gはまだ利用可。また、貼り付けた画像に[Image #N]チップが插入され、プロンプト内での位置指定が容易になった。

** агента向け frontmatter の initialPrompt** 支持が追加された。これにより、最初のターンで自动的にサブミッションされるプロンプトを定义でき、より细腻なエージェント制御が可能になる。

## セキュリティとパフォーマンス

これらの变更に加え、众多のバグ修正が実施されている。macOSでの終了时的ハング、画面点灭、非常大的ファイルの差分タイムアウト等问题が修正された。また、ボイス入力开始時のUIフリーズ问题や、MCP_CONFIG CLIフラグが允许リスト/拒否リストのmanaged policyをバイパスしていた问题も修正されている。

Bedrock SDKのコールドスタート延迟 개선、--resume使用时的メモリ使用量改善、插件 起动时の高速化など、パフォーマンスの改善も多层的に実施されている。
