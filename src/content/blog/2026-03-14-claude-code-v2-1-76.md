Anthropic has released Claude Code v2.1.76 on March 14, 2026. This version is a maintenance update focusing on security patches and stability improvements.

## Overview of Changes

This release includes fixes for issues reported in previous versions along with overall performance improvements. For detailed changes, please refer to the official release notes.

### Security Fixes

This release contains security patches addressing vulnerabilities identified in previous versions. Claude Code users are strongly recommended to update to this version as soon as possible.

### Stability Improvements

Various stability improvements have been implemented to enhance the overall user experience. These include bug fixes and optimizations that address issues reported by the community.

## How to Update

Claude Code updates automatically. To update manually, run:

```bash
claude update
```

Alternatively, you can download the latest version from the Claude Code website (claude.com/claude-code).
