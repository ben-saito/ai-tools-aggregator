Cursor announced on March 11th the launch of a new marketplace featuring over 30 plugins from partners including Atlassian, Datadog, GitLab, Glean, Hugging Face, monday.com, and PlanetScale.

## New Plugins

Cursor has released over 30 new plugins at [cursor.com/marketplace](https://cursor.com/marketplace). These plugins enable developers to read from, write to, and take actions across a broader stack directly from Cursor.

### Project Management

Integrations with monday.com and Linear allow creating tickets, updating issues, and managing workflows directly within Cursor.

### Monitoring and Observability

The Datadog integration enables Cursor agents to execute error tracking, performance monitoring, and alert review directly.

### Version Control and CI/CD

GitLab integration allows managing merge requests, pipeline monitoring, and deployment operations directly from Cursor.

### Knowledge Search

Glean integration enables searching internal documentation and knowledge bases, incorporating relevant information into agent context.

### AI/ML Workflows

Hugging Face integration allows searching, deploying, and running inference on models directly within Cursor.

### Databases

PlanetScale integration enables schema querying, query execution, and data manipulation directly from Cursor.

## MCP and Agent Support

Most plugins contain [MCP (Model Context Protocol)](https://cursor.com/docs/context/mcp) implementations that cloud agents can use when kicked off manually or triggered automatically through [automations](https://cursor.com/docs/cloud-agent/automations).

This enables delegating routine development tasks to agents, allowing human developers to focus on more complex decision-making.

## Automation Integration

The new plugins work well with the recently announced [automation features](https://cursor.com/blog/automations). Agents can run on schedules or be triggered by events from Slack, Linear, GitHub, PagerDuty, and webhooks.
