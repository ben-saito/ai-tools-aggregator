Anysphere has released Cursor 3, a major version update to its AI code editor. The new interface is built around agents, providing a faster, cleaner, and more powerful development environment.

## What is Agents Window

The new Cursor interface introduces "Agents Window" that allows running multiple agents in parallel across repos and environments—locally, in worktrees, in the cloud, and on remote SSH. This significantly improves development workflows.

### Key Features

- **Multi-workspace support**: The new interface is inherently multi-workspace, allowing humans and agents to work across different repositories
- **Parallel agent execution**: All local and cloud agents appear in the sidebar, enabling execution of multiple agents concurrently
- **Cloud agent demos and screenshots**: Cloud agents produce demos and screenshots of their work for easy verification
- **Seamless handoff between local and cloud**: Quickly move agent sessions from cloud to local or local to cloud
- **New diffs view**: Faster editing and review with a simpler UI, plus staging, committing, and PR management

## Agent Tabs

Agent Tabs allow viewing multiple chats side-by-side or in a grid, making it easier to manage multiple agent sessions simultaneously.

## Security and Privacy

Rather than forking VSCodium, Cursor 3 builds the new interface from scratch, centered around agents. This provides enhanced security and privacy for users.

## How to Try

Upgrade Cursor and type `Cmd+Shift+P` → `Agents Window` to try the new interface. You can switch back to the Cursor IDE anytime, or have both open simultaneously.

For more details, see the [Cursor documentation](https://cursor.com/docs/agent/agents-window).
